Je me fais tout seul, je profite tout seul.

Créé par André Orine Beberoo
🏆 Le Bot Difficile reste jouable en mode normal. La règle spéciale ne s’active que si tu coches « Mode difficile » ci-dessous.
🏆 Victoires contre le Bot Difficile : 0 • Série : 0/5
Choisis de créer ou rejoindre une partie.
🔴 0
Ronds sélectionnés : 0/4
🔵 0
Choisis directement 1 à 4 cases, puis appuie sur « J'ai fini ».
Règles :
• À ton tour, clique sur 1 à 4 cases pour placer tes ronds.
• Tu peux choisir les cases dans l’ordre que tu veux.
• Les cases jouées pendant un même tour doivent former une ligne horizontale ou verticale sans trou : aucune case vide ne peut être laissée entre deux ronds joués.
• Les lignes existantes peuvent être complétées ou prolongées : il est autorisé de jouer entre deux points déjà présents.
• Il n’est plus interdit de couper ou de croiser une ligne existante.
• Quand il ne reste qu’une seule case vide, le joueur qui doit la jouer perd immédiatement : le dernier rond ne peut pas être joué.
• En mode difficile, le nombre de ronds joué doit être différent de celui du tour précédent (sauf s'il est impossible physiquement de faire une autre quantité sur le plateau).
